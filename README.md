# HR-Attrition-Dashboard
HR Analytics Dashboard using Power BI

📌 Project Overview

This project focuses on analyzing employee attrition using Power BI. The dashboard provides insights into employee turnover patterns, job satisfaction, and other factors influencing employee attrition.

The objective is to help HR teams and management understand why employees leave the organization and identify areas where employee retention strategies can be improved.

🎯 Project Objectives

Analyze overall employee attrition.

Identify employee attrition trends across different departments.

Understand attrition based on age, gender, education, and job role.

Analyze the relationship between job satisfaction and employee turnover.

Identify key factors contributing to employee attrition.

Build an interactive dashboard to support HR decision-making.

🛠️ Tools & Technologies Used

Power BI Desktop – Dashboard development and data visualization.

Power Query – Data cleaning and transformation.

DAX (Data Analysis Expressions) – Calculated measures and KPIs.

Microsoft Excel – Dataset and initial data preparation.

📊 Dashboard Features

The dashboard includes the following key performance indicators (KPIs):

Total Employees

Attrition Cost

Attrition Rate

Active Employees

Employees left

Employee attrition by gender

Attrition by age group

Attrition by department

Attrition by job role

Attrition by job satisfaction

Attrition by marital status

Attrition by salary range

Attrition by overtime

Attrition based on years at the company

📈 Key Insights

The dashboard helps identify:

Departments experiencing higher employee turnover.

Employee age groups with higher attrition.

Job roles with significant attrition rates.

Differences in attrition across gender groups.

The impact of job satisfaction on employee retention.
